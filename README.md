# ECHOPULSE - PAINEL DE MONITORAMENTO CLIMÁTICO

## Sobre o Projeto:

O EchoPulse é um painel de monitoramento climático que reúne os principais dados meteorológicos em uma interface organizada e compreensível. O sistema permite consultar condições climáticas de uma localização informada pelo usuário, apresentando dados atuais, previsão do tempo e informações relacionadas a eventos climáticos potencialmente perigosos. Seu objetivo é manter o usuário informado sobre as condições mais relevantes do clima em sua região, permitindo o acompanhamento das mudanças meteorológicas e contribuindo para a tomada de decisões mais conscientes no dia a dia.

Em um cenário atual marcado pelas mudanças climáticas e pela crescente ocorrência de eventos meteorológicos extremos, o EchoPulse busca facilitar o acesso à informação climática, auxiliando as pessoas a compreender melhor as condições ambientais ao seu redor e a se preparar para possíveis situações de risco. Dessa forma, a iniciativa procura contribuir para a segurança, o planejamento pessoal e a conscientização sobre a importância do monitoramento climático.

O projeto foi desenvolvido como trabalho de conclusão do curso Python Pro, da Koodland, com o propósito de aplicar na prática os conhecimentos adquiridos em programação e desenvolvimento de sistemas, integrando diferentes tecnologias para criar uma ferramenta funcional, informativa e acessível.

## Funcionalidades

- Consulta de condições climáticas por coordenadas geográficas.
- Exibição da temperatura atual e da sensação térmica.
- Apresentação das temperaturas mínima e máxima.
- Previsão meteorológica para os próximos dias.
- Exibição de umidade, pressão atmosférica, precipitação e velocidade do vento.
- Representação visual das condições climáticas por meio de ícones.
- Consulta e apresentação de alertas meteorológicos, conforme a integração de dados disponível.

## Tecnologias utilizadas:

- Python: Processamento dos dados e lógica de aplicação.
- HTML: Interface e Frontend.
- CSS: Personalização e Estrutura da Página.
- Flask: Estrutura do servidor Web.
- Jinja2: Integração dos dados com a página web.
- Open Meteo: API das informações climáticas.
- GDACS: Obetnção dos alertas climáticos.

## Estrutura do projeto:

- main.py — aplicação Python e processamento dos dados.
- templates/ — páginas HTML.
- static/css/ — arquivos de estilo CSS.
- static/images/ — logotipo e ícones utilizados na interface.

## Fonte dos dados:

Os dados meteorológicos são obtidos por meio da API Open-Meteo. A disponibilidade e a abrangência das informações dependem dos serviços e das fontes integradas ao sistema.
